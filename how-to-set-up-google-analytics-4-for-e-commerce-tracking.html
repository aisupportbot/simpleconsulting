How to Set Up Google Analytics 4 for E-commerce Tracking

By Scott Nguyen · Published Jul 31, 2024 · Updated 2026-09-15

In this article
  1. Define the events and values
  2. Implement and validate
  3. Separate key events and advertising conversions
  4. Choose retention and access deliberately

GA4 uses events to describe the customer journey. An e-commerce measurement plan should distinguish browsing, checkout and purchases, and reconcile reported purchases with the order system.

Define the events and values

Agree on events such as product views, add-to-cart, checkout and purchase. Purchase reporting needs appropriate transaction identifiers, value and currency. Avoid firing the same purchase again when a confirmation page is refreshed.

Implement and validate

Use your platform integration, tag setup or an agreed implementation. Test representative orders, refunds where applicable and consent behaviour. Inspect the data before using it for advertising decisions.

Separate key events and advertising conversions

GA4 key events and Google Ads conversion actions have related but distinct configurations. Confirm which actions are imported or created in Ads and whether campaigns actually use them.

Choose retention and access deliberately

Data-retention settings affect particular user and event data, not every aggregate report in the same way. Select settings suited to the reporting need and privacy requirements. Document refresh timing, access and limitations.
