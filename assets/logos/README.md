# Retailer logos for the homepage

The homepage logo bar currently loads each logo from logotyp.us. If a logo can't load, the brand name shows as grey text instead.

To use official files instead: save them here (for example amazon.svg, walmart.svg, best-buy.svg, costco.svg, wayfair.svg, lowes.svg, loblaws.svg, shopify.svg, groupon.svg), then change each logo's `src` in content/homepage.src to `/assets/logos/<name>.svg` and run `npm run build`.

Get logos from each company's official brand or press page and follow their usage rules. Costco's logo standards require approval before display (costcologorequest@costco.com).
